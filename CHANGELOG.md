# Changelog

## 2.0.0 — 2026-09-11

- Nuovo core senza categorie hard-coded e configurazione INI non eseguibile.
- Adattatori di download/parsing separati, con comandi argv configurabili.
- Generazioni atomiche, lock, ultima lista valida e soglie configurabili.
- IPv4/IPv6, sottrazione esatta whitelist e aggregazione senza ampliamento.
- Generazione zone e configurazioni DNS da parametri; precedenza deterministica.
- Upload SSH/rsync, controllo remoto, reload e ripristino del symlink su errore.
- Rotte Linux limitate a tabella/protocollo configurati.
- Log JSONL UTC, hash, statistiche per categoria e codici di uscita affidabili.
- Bootstrap non distruttivo; dipendenza PDF opzionale con conferma.
- Test automatici, CI Python 3.8.10 e documentazione italiana.
